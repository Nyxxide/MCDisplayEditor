Instructions

Editor Controls

Left Click: Select Block/Group

Alt + Left Click in Editor: Place Selected Block.

X + Left Click in Editor: Place Selected Block Against Other Object Surface.

* Holding Alt/X Before Clicking Shows Placement Location

Ctrl/Cmd + Click: Multiselect

Ctrl/Cmd + Drag: Box Select

Editor Hotkeys

T: Translate

R: Rotate

S: Scale

H: Change Grid Interval (1.0/0.25)

G: Group Selected

U: Ungroup Selected

Ctrl/Cmd + C: Copy Selected

Ctrl/Cmd + V: Paste Selected

Ctrl/Cmd + Z: Undo

Ctrl/Cmd + Y: Redo

Ctrl/Cmd + S: Save

Delete: Delete Selected

Arrow keys: Move Selected 0.001

Shift + Arrow: Move Selected 0.25

Tab + Arrow: Move Selected 1.0

`: Snap Selected to Nearest "Block"

Top Bar UI

: Save the current editor model

: Load a saved editor model

: Show or hide the editor grid

: Open this help menu

: Import an external reference model

: Import block_display commands into the editor

: Open premade saved models

Selected Block UI

X/Y/Z: Depending on mode. Transforms on that axis

Properties Dropdown: Changes block(s) visually if applicable

Tags: List of tags to reference the entity(s) by in game

View Range: How many blocks away the entity(s) is visible from

Brightness: Light level applied to the entity(s). If empty, world light level applies

Shadow Radius: Size of the shadow of the selected entity(s)

Shadow Strength: Darkness of the shadow of the selected entity(s)

Exports

Export Many: Gives one summon command per entity for all entities in editor - (One summon per object)


Export One: Gives Minecart Chain summon commands that fit as many entity summons as possible into a "One-Command-Block" command - (One command for everything in editor/multiple commands if command block character limit exceeded)
