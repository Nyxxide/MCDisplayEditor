Instructions

Editor Controls

Left click: select

Alt + Left click on ground: place selected block

Ctrl + Click / Ctrl + Drag: multiselect / box select

W / E / R: translate / rotate / scale

Delete: delete selected

Transform Shortcuts

Arrow keys: tiny nudge

Shift + Arrow: 0.25 nudge

Tab + Arrow: 1.0 nudge

` : snap selected to half-block centers

Grouping

G: group selected

U: ungroup selected group

Clipboard

Ctrl/Cmd + C: copy selected

Ctrl/Cmd + V: paste selected

Exports

Use the sidebar buttons to export one summon per entity or a minecart-chain one-command export.
